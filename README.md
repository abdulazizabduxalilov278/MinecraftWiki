## 🚀 Vercel orqali 24/7 Serverga Yuklash (Deploy)

### 1-Usul: Avtomatik fayl orqali
Loyiha papkasidagi `deploy-vercel.bat` faylini ikki marta bosing:
1. Brauzerda Vercel akkauntingizni tasdiqlang.
2. Loyiha avtomatik ravishda Vercel serveriga 24/7 bepul joylashadi.

### 2-Usul: GitHub orqali
1. Loyihani GitHub-dagi yangi repozitoriyingizga yuklang (`git push`).
2. [Vercel.com](https://vercel.com) saytiga kiring va GitHub akkauntingiz bilan kiring.
3. **"Add New... → Project"** tugmasini bosing va ushbu repozitoriyani tanlang.
4. **"Deploy"** tugmasini bosing — 1 daqiqada sayt butun dunyo bo'ylab 24/7 ishlay boshlaydi!
5. Vercel loyiha sozlamalaridan **Settings → Domains** ga kirib `MinecraftWiki.uz` domenini ulang.
